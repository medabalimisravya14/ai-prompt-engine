# AI Prompt Engine ✨

An intelligent Streamlit app that auto-detects typos and grammar issues in user prompts.

### Features
- ⚠️ **Error Detection**: Finds spelling mistakes like `writ` -> `write`
- 💡 **Did you mean?**: Suggests corrected prompt before generating
- 🚀 Powered by Google Gemini

### How it works
Unlike ChatGPT which silently corrects, our app TEACHES the user:
1. User types: `writ a stroy abuot robo`
2. App shows: `Possible typo: 'writ'` + `Did you mean: Write a story about robot?`
3. User clicks `Use corrected` and gets perfect result!
